# قَيْد - المحاسب الذكي

مشروع Flutter أولي باللغة العربية وواجهة من اليمين إلى اليسار.

## التشغيل
1. ثبّت Flutter SDK.
2. افتح مجلد المشروع في Android Studio أو VS Code.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```

## الملفات
- `lib/main.dart`: الكود المصدري للتطبيق.
- `pubspec.yaml`: إعدادات المشروع.
